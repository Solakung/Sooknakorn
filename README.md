# 🏙️ สุขนคร — เกมใช้ชีวิตในเมืองอุดมคติ

เกม single player ภาษาไทย รันบนเบราว์เซอร์ล้วน (HTML/CSS/JS ไม่มี backend ไม่ต้อง build) พร้อม deploy ขึ้น GitHub Pages ได้ทันที

คุณคือชาวเมืองคนหนึ่งในโลกปัจจุบัน ใช้ชีวิต 1 ปี (เริ่ม 4 ม.ค. 2570) ทำงาน ออม เรียน ดูแลสุขภาพ ผูกมิตร เปิดกิจการ และร่วมโหวตนโยบายเมืองทุกเดือน

**หน้าจอ:** ออกแบบสำหรับมือถือก่อน (ทดสอบที่ความกว้าง 360/412/768px ไม่มีการเลื่อนแนวนอน) ปุ่มในแต่ละสถานที่แบ่งเป็นแท็บ ผู้คน / กิจกรรม / ซื้อ-กิน / งานและเงิน / ชุมชน และซ่อนปุ่มที่ยังทำไม่ได้ไว้ (กดดูพร้อมเงื่อนไขได้)

## ระบบในเกม (วงจรเมืองที่เชื่อมกัน)

- **ตัวชี้วัดเมือง 10 ด้าน** (เศรษฐกิจ การจ้างงาน ที่อยู่อาศัย สาธารณสุข การศึกษา การเดินทาง สิ่งแวดล้อม ความปลอดภัย วัฒนธรรม ธรรมาภิบาล) ดึงกันและกันทุกวัน + งบคงคลัง + ประชากร
- **ประชามติรายเดือน**: ชาวเมืองเลือกนโยบาย (เสียงคุณมีน้ำหนักตามแต้มพลเมือง) โครงการที่ชนะใช้งบเมืองและเปลี่ยนตัวชี้วัด
- **ชีวิตผู้เล่น**: พลังงาน/อิ่ม/สุขภาพ/อารมณ์/ความฟิต, ทักษะ 5 ด้าน, วุฒิการศึกษา, ใบรับรอง
- **งาน**: 8 สายอาชีพ × 3 ระดับ, สมัครงาน, ขอเลื่อนตำแหน่ง, ลา/ขาดงาน/ถูกเลิกจ้าง, เงินทดแทนว่างงาน, ภาษีและประกันสังคม
- **การเงิน**: ออม, กองทุน, สินเชื่อ (ส่วนบุคคล/ชุมชน/กยศ./รถ/บ้าน), เครดิตสกอร์, ค่าเช่า/บิลรายเดือน, ซื้อบ้านมั่นคง
- **ตาข่ายนิรภัย**: ธนาคารอาหาร, เงินช่วยเหลือฉุกเฉิน, สวัสดิการ, ที่พักพิง, ตรวจสุขภาพฟรี
- **กิจการของตัวเอง** 4 แบบ, **เมืองการเดินทาง** (เดิน/จักรยาน/รถเมล์/รถ), **งานอาสา** ทุกย่าน
- **ครอบครัว**: พ่อแม่ต่างจังหวัด (โทร/โอนเงิน/กลับบ้าน), คนรัก 3 คนให้เลือกคบ → เดท → เป็นแฟน → แต่งงาน → มีลูก (ต้องดูแลความสัมพันธ์ ไม่งั้นอาจเลิกกัน)
- **ที่ทำงาน**: หัวหน้าและเพื่อนร่วมงาน (สุ่มชื่อ) ความสนิทกับหัวหน้าช่วยให้เลื่อนตำแหน่งเร็วขึ้นและรอดจากการเลิกจ้าง
- **ชีวิตจริงรอบตัว**: สภาพอากาศรายวันตามฤดู (พายุงดกิจกรรมกลางแจ้ง, ฝนทำให้เดินทางเหนื่อย), ประกันสุขภาพ, กองทุนสำรองเลี้ยงชีพ (นายจ้างสมทบ), สลากกินแบ่งออกทุกวันที่ 1 และ 16, โซเชียลมีเดีย, ยื่นภาษีประจำปี, ทริปท่องเที่ยว
- **การเมืองท้องถิ่น**: ประชามติทุกเดือน + เลือกตั้งสภาเมืองทุกพฤศจิกายน (3 กลุ่ม นโยบายต่างกัน)
- เหตุการณ์กว่า 85 แบบ (รวมเทศกาลไทยตามปฏิทิน: วันเด็ก วาเลนไทน์ ตรุษจีน วันพระใหญ่ สงกรานต์ กินเจ ปลายปี เคานต์ดาวน์ และโบนัสปลายปี) เช่น ใบสั่งจราจร ท่อรั่ว พ่อแม่ป่วย งานแต่งเพื่อน งานเลี้ยงรุ่น เจ็บป่วยหนัก ลื่นล้ม
- **อายุและรุ่นต่อรุ่น**: ทุกคนมีอายุ (ตั้งความเร็วในเมนู: 1 ปีเกม = 1/5/10 ปีชีวิต) ชาวเมืองเรียนจบ แต่งงาน มีลูก ย้ายเข้า-ออก เกษียณ และจากไป บทบาทสำคัญ (หมอ ครู แม่ค้า เจ้าของหอ ฯลฯ) มีผู้สืบทอด คนใหม่ย้ายเข้าตามความน่าอยู่ของเมือง เด็กที่เกิดในเมืองโตเป็นชาวเมืองรุ่นใหม่ ลูกของผู้เล่นโตตามวัย (ค่าใช้จ่ายเปลี่ยนตามวัย) จนเป็นผู้ใหญ่ ผู้เล่นเกษียณรับบำนาญได้ และเมื่อถึงบั้นปลายเลือกเล่นต่อเป็นลูกได้
- **บทสนทนา (v2.0)**: กด "พูดคุย" แล้วเลือกหัวข้อ — คำทักทายเปลี่ยนตามความสนิท เวลา อากาศ และเรื่องที่เพิ่งเกิด ตัวละครหลักทั้ง 17 คนมีบทเฉพาะตัว (ชีวิตช่วงนี้ ความเห็นต่อเมือง คำแนะนำตามอาชีพ และเรื่องส่วนตัวที่เล่าทีละตอนเมื่อสนิท) คนย้ายเข้าใหม่มีบทตามอาชีพ รวมกว่า 1,400 ประโยค (ตัวละครหลัก ~1,050 • ชาวเมือง/คนย้ายเข้า/เด็ก ~370 • คำทักตามสถานการณ์ 62) มีหัวข้อ "😄 เรื่องสนุก" เพิ่มใน v2.2 เขียนไว้ล่วงหน้าทั้งหมด ไม่ต้องใช้ AI หรืออินเทอร์เน็ต
- **โลกที่มีชีวิต**: NPC เป็นเพื่อน/ทะเลาะ/แต่งงานกันเอง มีข่าวซุบซิบที่ไปถึงหูอีกฝ่าย และเพื่อนของเพื่อนจะชอบเราตามไปด้วย ร้านค้าของชาวเมืองเปิด เจ๊ง หรือขยายสาขาตามเศรษฐกิจ เงินเฟ้อ ค่าแรง และราคาบ้านขยับทุกปี
- **สุขภาพระยะยาว**: เบาหวานและความดันเกิดจากพฤติกรรมสะสม (ตรวจพบตอนตรวจสุขภาพ ต้องกินยาและตรวจติดตาม หายเข้าระยะสงบได้) และภาวะหมดไฟจากการทำงานหนัก
- **งานอดิเรก**: ดนตรี กีฬา ทำอาหาร ศิลปะ ประกวดประจำเดือนชิงรางวัล
- **กฎหมาย**: ข้อพิพาทกับเพื่อนบ้าน (คุยเอง/ไกล่เกลี่ย/ฟ้องศาล) หน้าที่ร่วมพิจารณาคดี คลินิกกฎหมายฟรี และช่วยไกล่เกลี่ยชาวเมืองที่ทะเลาะกัน
- **ลูก**: เกิดมาพร้อมความถนัดและนิสัย ปั้นความสามารถ 5 ด้านด้วยกิจกรรม เลือกโรงเรียนประถมและสายมัธยม อาชีพตอนโตเป็นไปตามสิ่งที่ปั้น
- **การเมือง**: ลงสมัครสมาชิกสภาเมือง (ยื่นญัตติเพิ่มงบ) แล้วขึ้นเป็นนายกฯ (ปรับงบ อนุมัติโครงการเอง) โดยมีคะแนนนิยมที่ต้องรักษา
- **แผนที่เมืองแบบภาพ**: เห็นย่าน แม่น้ำ จำนวนคนในแต่ละที่ ตึกเพิ่มตามประชากร และรถไฟฟ้า/เลนจักรยานเมื่อโครงการเสร็จ (สลับเป็นแบบรายการได้)
- จบปีได้คะแนน 6 ด้าน + เกรด S–D ตามเป้าหมายชีวิตที่เลือก (เล่นต่อปีที่ 2 ได้)

## ปรับแต่งเนื้อหา

เนื้อหาเกือบทั้งหมดเป็นข้อมูลล้วนใน `js/data.js`, `js/npcs.js`, `js/events.js` — เพิ่มอาชีพ หลักสูตร นโยบาย ตัวละคร หรือเหตุการณ์ใหม่ได้โดยเพิ่มรายการในตารางโดยไม่ต้องแตะระบบหลัก

ตัวละคร เหตุการณ์ และองค์กรทั้งหมดเป็นเรื่องสมมติ
